# Unit Testing Implementation

The unit test cases for this enterprise application have been implemented as part of the core project:

**[1_Design_a_3-tier_enterprise_application_architecture_for_a_given_system](https://github.com/Abhishekdixit75/SBMEAN/tree/main/SB/1_Design_a_3-tier_enterprise_application_architecture%20for%20a%20given_system)**

### Where to find the tests:
You can find the test files in the following directory:
- `src/test/java/com/example/demo/`

### Key Tests Demonstrated:
- **Service Layer Testing**: Verifying business logic in isolation using Mockito.
- **Repository Testing**: Verifying database interactions with `@DataJpaTest`.
- **Integration Testing**: Verifying the full application context with `@SpringBootTest`.

Refer to the main project's test suite for complete implementation details.

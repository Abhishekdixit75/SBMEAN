# Angular User Registration and Login

This folder contains an Angular application that demonstrates user registration, login, routing, forms, and a simple authentication service.

## Prerequisites

- Node.js installed
- npm installed

Check your versions:

```bash
node --version
npm --version
```

## Setup

Open a terminal in this folder:

```bash
cd MEAN/implementation_angular_application_user_registration_and_login
```

Install dependencies:

```bash
npm install
```

## Run

Start the Angular development server:

```bash
npm start
```

Open the application:

```text
http://localhost:4200
```

The app reloads automatically when source files are changed.

## Build

Create a production build:

```bash
npm run build
```

The build output is generated in the `dist/` folder.

## Test

Run tests:

```bash
npm test
```

## Important Files

- `src/app/components/register` - Registration component
- `src/app/components/login` - Login component
- `src/app/services/auth.service.ts` - Authentication service
- `src/app/app-routing.module.ts` - Application routes

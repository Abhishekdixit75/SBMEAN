# React Components and Hooks

This folder contains a React application created with Vite. It demonstrates React components, state, and hooks.

## Prerequisites

- Node.js installed
- npm installed

Check your versions:

```bash
node --version
npm --version
```

## Setup

Open a terminal in this folder:

```bash
cd MEAN/implementation_reactjs_components_and_hooks
```

Install dependencies:

```bash
npm install
```

## Run

Start the Vite development server:

```bash
npm run dev
```

Open the local URL shown in the terminal. Vite usually uses:

```text
http://localhost:5173
```

## Build

Create a production build:

```bash
npm run build
```

## Preview Production Build

Preview the generated build locally:

```bash
npm run preview
```

## Lint

Run ESLint:

```bash
npm run lint
```

## Important Files

- `src/App.jsx` - Main React component
- `src/main.jsx` - React entry point
- `src/index.css` - Application styles
- `vite.config.js` - Vite configuration
